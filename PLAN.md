# План работ: LestingCraft → плотная, реалистичная лесная графика

## Целевой референс
Скриншот пользователя: густой лес, террасированный воксельный рельеф, высокая трава,
слоистая листва, читаемые тени, естественное небо и кирка в руке. Цель — не «накрутить bloom»,
а исправить причины, по которым текущий лес выглядит плоско и черно.

## Этап 1 — аудит и гигиена (готово)
- Изучены рендер-пайплайн, генерация мира, материалы, животные, боссы, UI, CI и документация.
- Найдены реальные кадры текущей ветки: листва проваливается в чёрный, трава редкая,
  постобработка пересвечивает картинку, настройки качества не разделены для ПК и Android.
- Добавлены отсутствующие `.meta`, read-only hygiene gate и проверка на очевидные секреты.
- README и этот план приведены к фактическому состоянию кода.

## Этап 2 — единая политика качества (готово)
- `VisualQualityPolicy`: Mobile / Balanced / High / Ultra / Cinematic.
- Миграция старых PlayerPrefs: legacy 0 → High, legacy 1 → Ultra, а не в Mobile/Balanced.
- Android ограничен по render scale, теням, дальности и пресету; скрытого авто-понижения по FPS нет.
- Editor bake и runtime используют один источник параметров постобработки.
- Headless core test + EditMode tests закрепляют миграцию, лимиты и монотонность бюджетов.

## Этап 3 — лес, листва, трава (готово к GPU-проверке)
- Листва и сакура получают ограниченный sky-bounce, чтобы теневая крона не становилась чёрной.
- Нормали листвы смягчены; параллакс отключён для листвы.
- Трава: 5 явных бюджетов густоты/сегментов, выше и плотнее на старших пресетах, без коллизий.
- Skylight volume: half-texel clamp против утечек на границе объёма.
- Bloom/contrast/saturation/vignette снижены до естественного уровня; хроматическая аберрация убрана.

## Этап 4 — интерфейс и модели (готово к проверке)
- Tooltip компактнее и не закрывает пол-инвентаря; прочность не подменяет количество предмета.
- Книга рецептов: поиск и фильтр «помещается в сетку».
- Настройки: явная шкала пресетов, мобильные ограничения, честная подпись про URP/RT.
- Safe-area fit для вырезов/жестовых полос на Android.
- Кольцо босса и телеграф ударной волны собраны из сегментов, а не из сплошной квадратной плиты.

## Этап 5 — проверка и поставка (в работе)
- Локально: hygiene, art/content/render contracts, visual quality core.
- Облако: EditMode tests, Linux player build, `-lc-visual-review` — 7 реальных кадров.
- Отдельная ветка `agent/forest-visual-overhaul`; `main` не меняется до проверки.
- Релиз и теги не публикуются автоматически.

## Честные ограничения
- Это URP-растеризация, не hardware ray tracing и не path tracing.
- Карты материалов — производные PBR, не фотограмметрические сканы.
- Кадр из CI на llvmpipe подтверждает работоспособность и композицию, но не FPS на ПК/телефоне.
- Для финальной оценки нужны кадры и замеры на целевом Windows-ПК и Android-устройстве.
