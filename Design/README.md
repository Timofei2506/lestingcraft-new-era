# Новый дизайн: меню и сайт

`new-era-menu-mock.html` — интерактивный макет игрового меню, который можно
открыть в браузере и потыкать. Один файл, без внешних запросов (арт вшит
в base64), поэтому работает и в предпросмотре, и локально.

Экраны макета: главное меню, мультиплеер (адрес + порт, список серверов),
друзья (онлайн, заявки), маркетплейс (витрина, лоты, пополнение).

## Визуальная система

| Токен | Значение | Где используется |
| --- | --- | --- |
| `--ink` / `--deep` | `#04090a` / `#071113` | фон, стеклянные панели |
| `--amber` | `#ffb257` | главное действие, цена, акцент |
| `--mint` | `#6fe3c0` | «в сети», успех, вторичное действие |
| `--violet` | `#9d8bff` | планы, нейтральная информация |
| `--danger` | `#ff7a5c` | «сервер полон», ошибки |

Правила: стекло + тонкая рамка вместо тяжёлых заливок; один тёплый акцент на
экран; арт всегда под тёмным градиентом, чтобы текст читался; радиусы 13–20px;
анимация 0.2–0.3s `cubic-bezier(.2,.8,.2,1)`; всё уважает
`prefers-reduced-motion`.

## Что уже в сайте

`Website/public/style.css` переписан на эту систему, `index.html` получил
секцию «Экосистема». Сетка, id и data-атрибуты, за которые цепляется
`app.js`, сохранены — 31 юнит-тест и 14 браузерных тестов проходят.

## Что дальше по экранам Unity

Макет описывает целевое поведение: мультиплеер как список серверов с полем
«адрес + порт», создание сервера из паузы, друзья, маркетплейс. Перенос в
Unity — отдельная задача: нужны префабы, анимации и подключение к Supabase.
