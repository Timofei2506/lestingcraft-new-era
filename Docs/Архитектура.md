# Архитектура LestingCraft: New Era

## Стек

| Слой | Решение | Зачем |
|---|---|---|
| Движок | Unity 6 LTS (6000.x), URP | Стабильность, воксель-перф, текущие билды Windows x64 |
| Генерация/мешинг | Burst + Jobs + Collections | Террейн и меши чанков вне главного потока |
| Шум/биомы | FastNoiseLite (MIT) + свой слой биомов | Проверенная база |
| Ввод | Input System | Ребиндинг, гибкость |
| Сохранение | Бинарные чанки + JSON-мета | Быстро и просто |
| Тесты | Unity Test Framework (EditMode) | Ядро мира — под тестами |
| CI/CD | GitHub Actions + game-ci | Тесты и билды в облаке, без локального Unity |

## Подсистемы

```
WorldService ── ChunkManager ── ChunkData (16×16×256)
     │              │
     │              ├── TerrainGenerator (Burst-job: шум, биомы, пещеры, руды)
     │              ├── MeshBuilder (Burst-job: greedy-мешинг, коллизии)
     │              └── ChunkStorage (сериализация на диск)
     ├── BlockRegistry (id → свойства: твёрдость, свет, лут)
     ├── EntityManager (мобы, спавнеры, AI)
     ├── PlayerSystems (инвентарь, крафт, статы, строительство)
     ├── DimensionSystem (порталы, параметры измерения, атмосфера)
     ├── BossSystem (арены, фазы — ScriptableObject-конфиги)
     └── SaveSystem (мир + игрок + прогресс боссов)
```

## Правила

1. **Чистое ядро.** `World`-слой (BlockRegistry, ChunkData, генерация) не ссылается на UnityEngine, где это возможно → юнит-тесты без редактора.
2. **Логика не знает про UI** и наоборот — общаемся событиями/ScriptableObject-каналами.
3. **Всё числовое** (урон, броня, голод) — в ScriptableObject-конфигах: баланс правится без кода.
4. **Детерминизм.** Генерация мира — чистые функции в Burst-джобах: один сид → один мир (важно для мультиплеера в будущем).
5. **Бюджет времени чанка.** Генерация + мешинг одного чанка — жёсткий лимит мс; всё тяжёлое — в Jobs/Burst.

## Модули сборки (asmdef)

- `LestingCraft.Core` — ядро (мир, блоки, чанки, генерация).
- `LestingCraft.Tests.EditMode` — NUnit-тесты ядра.

Дальше по майлстоунам: `LestingCraft.Entities`, `LestingCraft.Player`, `LestingCraft.UI`.
