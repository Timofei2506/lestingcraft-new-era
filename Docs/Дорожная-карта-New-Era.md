# Дорожная карта: что просили, что сделано, что дальше

Документ фиксирует статус задач из запроса, чтобы не было «сделано на словах».
Три статуса: **Готово** (есть в `main` и проверено), **В работе** (есть
техническая основа, нужен клиент/ассеты), **Решение** (блокируется выбором,
который не могу сделать за вас).

## 1. Сервер и сборка

| Задача | Статус | Где |
| --- | --- | --- |
| Прод на Cloudflare отвечает актуальной версией | **Готово** | `Deploy coop server`, `test/deploy-smoke.mjs` |
| Автодеплой сервера при изменениях | **Готово** | `.github/workflows/deploy-server.yml` |
| Проверка прода по конкретному коммиту | **Готово** | `GIT_SHA` в `/health` |
| Ночной контроль дрейфа версий | **Готово** | `schedule: 17 */6 * * *` |
| Сборка Windows и Android в облаке | **Готово** (было) | `build.yml`, релиз `v0.5.2-era-v9` |

Прод сейчас: `rulesVersion 14`, `contentVersion 9`, commit `0eef142…`.

## 3. Экономика и социальное

| Задача | Статус | Где |
| --- | --- | --- |
| Схема БД: профили, кошелёк, журнал | **Готово** | `Supabase/schema.sql` |
| Маркетплейс игрок-игроку (эскроу, 5%) | **Готово** в БД | `market_list`, `market_buy` |
| Система друзей (заявки, блокировки) | **Готово** в БД | `friend_*` |
| Скины и косметика | **Готово** в БД | `store_items`, `entitlements` |
| Пополнение за реальные деньги | **Готово** в БД, **выключено** | паки `active = false` |
| Стартовые монеты | **Не выдаются** (как просили) | новый кошелёк = 0 |
| Экраны маркетплейса/друзей в игре | **В работе** | нужен клиент Unity |
| Приём платежей | **Решение** | нужен платёжный провайдер |

## 4. Игровой процесс

| Задача | Статус | Комментарий |
| --- | --- | --- |
| Мультиплеер как в Minecraft: список серверов, «адрес + порт» | **В работе** | сервер уже принимает `?clientRules=`-подключения и лобби, нужен экран в Unity |
| Создание сервера из одиночного мира (ESC) | **В работе** | API комнаты готов, нужен вызов из паузы |
| Больше мобов в обычном мире | **В работе** | таблицы фауны серверные (`Server/src/wildlife.js`) — расширяемо |
| Враждебные мобы | **В работе** | механика урона уже есть |
| Больше структур | **В работе** | `Server/src/structure-plan.js` |
| Боссы в обычном мире | **В работе** | движок боссов есть в сюжете, нужно вынести в мир |
| Реалистичное расположение планет | **В работе** | Unity: `Assets/Scripts/Runtime/Space*` |
| Нормальный шаттл | **В работе** | нужны модели + материалы |

## 5. Что нужно от вас

1. **Платёжный провайдер**: Stripe / Cloudflare-платежи / что-то ещё. Пока не
   выбран, паки выключены и монеты в игре получить нельзя — это честно.
2. **Supabase Auth на сайте**: экран входа — делать сейчас или после клиента?
3. **Unity-сборка**: правки графики, планет и шаттла проверяются только в Unity.
   Нужно, чтобы сборка проходила и скриншоты были — иначе «стало лучше» не проверить.
4. **Токены**: `ghp_…` из чата отозвать; для работы использовать secrets.
   Supabase-токен уже положен в secrets репозитория как `SUPABASE_ACCESS_TOKEN`.

## Порядок работ, который предлагаю

1. Экран мультиплеера и «Создать сервер» из паузы — самый заметный разрыв с
   ожиданием «как в Minecraft».
2. Подключить клиент к Supabase: друзья и маркетплейс на реальных данных.
3. Мобы, структуры, боссы — серверные таблицы, проверяются тестами.
4. Графика, планеты, шаттл — Unity, только с проверкой на скриншотах сборки.
5. Платежи — когда выбран провайдер.
