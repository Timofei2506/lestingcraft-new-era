## 3. Измерения
- Названия — **рабочие из кода**: Somnia (сон), Dream, Backrooms.
- Роль в кампании — **побочные данжи** (необязательные, с наградами).

### Backrooms
- **Белые лабиринты** (по мотивам Level 484 «Белизна»/«Белая Комната»,
  The Whiteout) **и другие уровни** — многоуровневость по вики Backrooms.
- Мобы: чёрные бактерии. Босс: Чёрная Бактерия (альфа).
- Вход: задыхание под песком/гравием (уже реализовано).
- Выход: **no-clipping** (канон Backrooms).

### Измерение сна (Somnia, сонный паралич)
- Это **та же локация, где игрок заснул**, в версии «сонного паралича»:
  реальность искажена, движение затруднено.
- Выход — **пережить паралич** (дождаться конца события), не дверь.
- Босс: «Тот, Кто Услышал».

### Мир ИИ (Dream / цивилизация ИИ)
- **Город будущего**: машины, дроны, люди-роботы.
- Босс: «Первый Узел».

## 4. Сюжет
- Кампания: Земля (старт, 3 босса) → подготовка → Солнечная система
  (Меркурий/Марс/Сатурн) → цивилизация ИИ → газовые гиганты (раздельный
  спавн в мультиплеере, деградация связи, встреча через шаттл) → финал;
  после финала Земля открыта.
- Реплики — Сцены 1-7 библии (уже в `Tools/build_chapter_one.py`).
- Имена-выдумки (без утверждения) запрещены.

## 5. Открытые флаги (см. обсуждение в чате)
- Совмещение ответов «ТКУ остаётся боссом Backrooms» и утверждённого
  списка «ТКУ (Somnia)»: рабочая схема — Бактерия-альфа = босс Backrooms,
  ТКУ = босс Somnia; автор может поменять местами.
- «Вестник Бури» — какой именно мир газового гиганта (кандидат: Венера,
  шторма).
