# LestingCraft: New Era — План разработки

> Воксельная песочница («майнкрафт-класс») на **Unity 6 LTS**, репозиторий на **GitHub**.
> Статус документа: **черновик плана v0.1** (обновляется по мере решений).
> Дата: 2026-10-14.

---

## 1. Концепт и столпы

**LestingCraft: New Era** — воксельная песочница с упором на исследование: не «ещё один клон», а игра, где главный козырь — **5 самобытных измерений**, связанных порталами, с **боссами в каждом** и финальной сюжетной аркой «Новой Эры».

Четыре столпа дизайна (всё, что им противоречит, вырезаем):

| Столп | Смысл | Проверка «прошёл/не прошёл» |
|---|---|---|
| **Мир** | Живые биомы, пещеры, структуры, 5 измерений | Игроку интересно просто идти вперёд 30 минут |
| **Вертикалька** | Добыча → крафт → экипировка → портал → босс | Понятный прогресс от кулака до финального босса |
| **Боссы** | Не «большой моб с ОЗ», а фазовые механики | У каждого босса ≥3 фазы и своя арена |
| **Производительность** | 60 FPS на средних ПК, мир без «дырок» | Стабильные кадры при полёте на максимуме прорисовки |

## 2. Игровое ядро (что вообще делаем)

### 2.1 Базовый цикл
Добыча ресурсов → крафт инструментов/брони → строительство базы → исследование пещер → сборка портала → новое измерение → ресурсы следующего тира → босс → следующее измерение.

### 2.2 Мир
- Бесконечный (по факту — очень большой) генерируемый мир из **чанков 16×16×256** (колонки), выгрузка/загрузка по дистанции.
- Биомы: леса, равнины, пустыни, горы, снежные биомы, болота, океаны, пещеры (3D-шум), рудные жилы по глубине.
- Структуры: деревни, башни, подземелья с комнатами-загадками, логова.
- Цикл дня/ночи, погода (дождь/снег/гроза).

### 2.3 Персонаж
- От первого лица, выживание: здоровье, голод, выносливость (спринт), урон от падения, температура (в огненных измерениях).
- Строительство/разрушение блоков, инструменты по тирам (дерево → камень → железо → алмазы-аналог → ресурсы измерений).
- Инвентарь + хотбар, верстак, печка, сундуки, простая система зачарований-аналогов («руны»).

### 2.4 Мобы
- Пассивные: аналоги свиней/коров/кур для еды.
- Нейтральные: деревенские жители (торговля).
- Враждебные: ночные мобы, пещерные, по измерениям свои.
- Спавн по освещённости, сложности и биому.

## 3. Пять измерений (главная фича)

> **Статус 2026-10-19:** в игре остаётся только Лестингия. Пеплоземье, Небокрай, Склеп Эха и Разлом Хаоса удалены из кода полностью (без восстановления). Космос станет **вторым измерением**, остальные вернутся по этапам. Таблица ниже — исходный план, а не текущее состояние.

| # | Измерение | Суть | Портал из | Босс | Награда-ключ |
|---|---|---|---|---|---|
| 1 | **Лестингия** (стартовый) | Классика: леса, горы, пещеры, деревни | — | **Страж Корней** (лесной голем, 3 фазы: корни → буря → ярость) | Сердце Леса → откроет руну портала |
| 2 | **Пеплоземье** | Огненные недра: лавовые моря, базальт, жар | Лестингия (руна Пепла) | **Магматический Кузнец** (ifrit-кузнец, призывает големов из лавы) | Пепельное Ядро → термозащита |
| 3 | **Небокрай** | Парящие архипелаги, ветер, воздушные течения | Пеплоземье (руна Ветра) | **Буревестник** (левиафан-шторм, арена в небе, фазы-вихри) | Крыло Бури → полёт/планер |
| 4 | **Склеп Эха** | Искажённая тьма, кристаллы, «шёпот» (дебаффы) | Небокрай (руна Эха) | **Пожиратель Эха** (стилth-дракон, крадёт уровни/опыт) | Око Эха → видит невидимое |
| 5 | **Разлом Хаоса** (финал) | Ломаная реальность, платформы в пустоте, аномалии | Склеп Эха (все 4 руны) | **Повелитель Хаоса** (финальный, 5 фаз, копирует ваши приёмы) | Завершение «Новой Эры», титры + NG+ |

Правила системы измерений:
- Порталы строятся игроком из материалов текущего тира.
- Каждое измерение — своя палитра, свои звуки, свои мобы, свой «гиммик» (жара → урон без защиты; ветер → паркур; эхо → дебаффы; хаос → ломающаяся геометрия).
- Босс — ворота дальше: без его трофея следующий портал не активируется.

## 4. Технический стек и архитектура

### 4.1 Стек
| Слой | Решение | Зачем |
|---|---|---|
| Движок | **Unity 6 LTS (6000.x)**, URP | Стабильность, хороший воксель-перф, билды на PC |
| Язык | C# | Стандарт Unity |
| Генерация/мешинг | **Burst + Jobs + Collections** | Генерация и меши чанков вне главного потока → 60 FPS |
| Шум/биомы | FastNoiseLite (MIT) + свой слой биомов | Проверенная база |
| Ввод | Input System | Гибкость, ребиндинг |
| UI | UI Toolkit (или uGUI, решим на M1) | Инвентарь/меню |
| Сохранение | Бинарные чанки + JSON-мета | Быстро и просто |
| Ассеты | Addressables | Память и подгрузка |
| Тесты | Unity Test Framework (EditMode) | Ядро мира — под тестами |
| CI/CD | **GitHub Actions + game-ci** | Автосборка Windows/Linux, автотесты |
| Мультиплеер | По решению пользователя: ранний кооператив 2–8 игроков; Cloudflare DO + portable Node/WebSocket | Отдельный ограниченный срез, самостоятельный хостинг |

### 4.2 Ключевые подсистемы
```
WorldService ── ChunkManager ── Chunk (16×16×256)
     │              │
     │              ├── TerrainGenerator (Burst-job: шум, биомы, пещеры, руды)
     │              ├── MeshBuilder (Burst-job: greedy-мешинг, коллизии)
     │              └── ChunkStorage (сериализация/диск)
     ├── BlockRegistry (id → свойства: твёрдость, свет, лут)
     ├── EntityManager (мобы, спавнеры, AI)
     ├── PlayerSystems (инвентарь, крафт, статы, строительство)
     ├── DimensionSystem (порталы, параметры измерения, шейдеры-атмосферы)
     ├── BossSystem (арены, фазы, поведение — ScriptableObject-конфиги)
     └── SaveSystem (мир + игрок + прогресс боссов)
```

Архитектурные правила:
- Игровая логика не знает про UI и наоборот (события/ScriptableObject-каналы).
- Всё «числовое» (урон, броня, голод) — в ScriptableObject-конфигах: баланс правится без кода.
- Генерация мира — чистые функции в Burst-джобах (детерминированно: один сид → один мир).

## 6. Дорожная карта

Оценка для одного разработчика + меня (пишу код, сценовые файлы, настройки). Грубо, в неделях активной работы:

| Майлстоун | Содержание | Критерий готовности | ~Срок |
|---|---|---|---|
| **M0. Фундамент** | Репо, Unity-проект, CI, схема чанка, реестр блоков | `ci.yml` зелёный, пустой мир крутится | 1–2 нед |
| **M1. Ядро мира** | Генерация террейна, биомы, пещеры, greedy-мешинг, чанк-стриминг, спавн | Бесконечный мир 60 FPS, без дыр в мешах | 3–4 нед |
| **M2. Выживание** | Ходьба/прыжки, ломание/установка блоков, инвентарь, крафт, печка, сохранение | Цикл «нашёл → сварил → построил» целиком | 2–3 нед |
| **M3. Жизнь мира** | Мобы, день/ночь, погода, деревни, структуры, лут | Ночь опасна, деревни находятся | 3–4 нед |
| **M4. Измерения** | Порталы, генерация 5 миров, атмосфера/шейдеры, ресурсы тиров | Все 5 измерений достижимы и различимы | 4 нед |
| **M5. Боссы** | 5 боссов, арены, фазы, трофеи, сюжетные заставки | Каждый босс — уникальный бой | 4 нед |
| **M6. Полировка** | Звук, VFX, баланс, оптимизация, меню, настройки, билды, титры | Играбельный релиз-кандидат | 3–4 нед |

**Итого: ~4–6 месяцев до v1.0** при регулярной работе. Внутри каждого майлстоуна — играбельный билд в Releases (никогда не «код в вакууме»).

Порядок вертикальных срезов (чтобы не строить «всё сразу»):
1. Сначала **1 биом + 1 моб + 1 босс Лестингии** — как образец качества.
2. Потом масштабируем приём на остальной контент.

## 7. Риски и как их гасим

| Риск | Последствие | Митигация |
|---|---|---|
| Производительность мешинга | Фризы при генерации | Burst/Jobs с 1-го дня, бюджет времени на чанк, профайлер в CI-чеклисте |
| Разрастание скоупа | Никогда не выйдет | Столпы + вырезание фич вне них; NG+ и мультиплеер — после 1.0 |
| Юридика («как майнкрафт») | Претензии Mojang | Никаких ассетов/текстур/имён/кода из Minecraft; только жанровые механики (они не защищены) |
| Лицензия Unity на CI | Билды в Actions не собираются | Личная лицензия (бесплатна) + секреты в GitHub Secrets; инструкция будет в Docs |
| Одиночный разработчик, выгорание | Стоп проекта | Короткие майлстоуны, билд каждые 2 недели, видимый прогресс в Projects |
