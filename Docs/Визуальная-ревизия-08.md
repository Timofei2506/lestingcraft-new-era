# Визуальная ревизия 08 — лесная экспедиция

Ветка: `agent/forest-visual-overhaul`. Цель — приблизить LestingCraft к референсу пользователя:
густой лес, террасированный рельеф, высокая трава, читаемая листва, естественное небо и кирка в руке.
Это итерация поверх существующего URP-пайплайна, а не замена движка и не обещание RTX.

## Что показал аудит реальных кадров

На кадрах текущей `main` (ERA-V9 showcase) было видно:

- листва и сакура почти чёрные, особенно в тени;
- трава редкая и низкая, лес не даёт глубины;
- bloom/contrast/saturation местами пересвечивают картинку;
- настройки качества фактически двухступенчатые и одинаково тяжёлые для ПК и Android;
- tooltip инвентаря слишком крупный, прочность подменяла количество стаки;
- книга рецептов без поиска/фильтра;
- кольцо босса и телеграф ударной волны выглядели как сплошные квадратные плиты;
- README/PLAN отставали от кода, у части исходников отсутствовали `.meta`.

## Изменения

### Единая политика качества

`Assets/Scripts/Presentation/VisualQualityPolicy.cs` — чистый C# без UnityEngine:

- Mobile / Balanced / High / Ultra / Cinematic;
- миграция legacy PlayerPrefs: `0 → High`, `1 → Ultra`;
- мобильные лимиты: render scale 0.65–1.0, тени до 2048, дальность до 4 чанков, без Cinematic;
- монотонные бюджеты травы, облаков, тумана, parallax/water steps.

`VisualSettings` применяет политику к URP asset, renderer feature и shader globals.
`VoxelWorld` перестраивает detail submesh по `DetailQuality`, а не по сырому `Preset`.
Editor bake и runtime используют `VisualSettings.ConfigureBaseVolume`, поэтому грейд больше не расходится.

### Листва и трава

- `VoxelPBR.shader`: листва/сакура получают ограниченный sky-bounce от цвета неба и daylight.
  Это художественное приближение канопного рассеяния, не SSS и не path tracing.
- Нормали листвы смягчены, параллакс для листвы отключён.
- `Grass.shader`: аналогичный ограниченный bounce для стеблей.
- `SurfaceDetailMesher`: 5 бюджетов густоты и сегментов; трава выше на старших пресетах.
  Геометрия остаётся детерминированной, без коллизий и без GameObject на стебель.
- `VoxelSky.hlsl`: half-texel clamp на границе skylight volume.

### Постобработка

Природный грейд стал спокойнее:

- bloom threshold 0.90, intensity 0.45, scatter 0.72;
- contrast 8, saturation 6, exposure 0.05;
- vignette 0.12, film grain 0.06, chromatic aberration 0;
- ACES сохранён.

Радиационные/ядерные override-эффекты сохранены, но базируются на тех же константах.

### Интерфейс

- Tooltip подстраивает высоту под число строк и не закрывает пол-инвентаря.
- Количество предмета больше не подменяется процентом прочности; прочность — полоса и tooltip.
- Книга рецептов: поиск по названию и фильтр «помещается в сетку».
- Настройки: явная шкала из пяти пресетов, мобильные ограничения, честная подпись про URP/RT.
- `UiSafeArea`: равномерный fit фрейма в `Screen.safeArea` для вырезов и жестовых полос.
- Исправлены дублирующиеся строки профиля и устаревшие подписи версии/платформы.

### Модели

- `PlanetaryBossController`: кольцо короны и телеграф ударной волны собраны из воксельных сегментов.
  Это читаемый силуэт вместо сплошной квадратной плиты; логика боя и loot не менялись.
- Животные сохранили articulated-риги и PBR-шкуру; отдельный review-кадр проверяет силуэты.

### Гигиена

- Добавлены отсутствующие `.meta` у исходников и PBR-текстур.
- `Tools/audit_hygiene.py`: missing/orphan meta и очевидные секреты — ошибка;
  байт-идентичные ассеты — информационный отчёт, потому что многие дубли намеренные
  (общие PBR-слои, шрифты сайта/игры, общая предметная графика) и удалять их по GUID нельзя.
- README и PLAN приведены к фактическому состоянию.

## Проверка

Локально:

```bash
python Tools/audit_hygiene.py
python Tools/check_art.py
python Tools/check_content.py
python Tools/check_nature_render.py
mcs -langversion:7.2 -out:/tmp/visual-quality-check.exe \
  Assets/Scripts/Presentation/VisualQualityPolicy.cs Tools/check_visual_quality_core.cs
mono /tmp/visual-quality-check.exe
```

Облако:

- `.github/workflows/core.yml` — headless core checks, включая visual quality и hygiene.
- `.github/workflows/visual-review.yml` — EditMode tests, Linux player build и `-lc-visual-review`.

`VisualReviewProbe` снимает 7 реальных кадров плеера:

1. меню;
2. естественный лес без HUD (кадр для сравнения с референсом);
3. лес с HUD;
4. животные;
5. босс с сегментным кольцом;
6. инвентарь и tooltip;
7. настройки пресетов.

## Ограничения

- URP-растеризация, не hardware ray tracing.
- PBR-карты производные, не фотограмметрические сканы.
- CI на llvmpipe подтверждает работоспособность и композицию, но не FPS/VRAM на ПК и телефоне.
- Для финальной приёмки нужны кадры и замеры на целевом Windows-ПК и Android-устройстве.
- Релиз и теги этой итерацией не публикуются.
