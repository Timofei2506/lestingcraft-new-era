# Итерация 08 — лаунчер и исправления Windows-версии

Проверено 15 октября 2026 года. Игровой код: `1d718db3e1dfd48945736300d9a0c6842640c4ca`. Исправленная Windows-версия прошла нативный smoke и доступна через закрытый тестовый канал. Репозиторий остаётся приватным, GitHub Release/тег не создавались.

## Как запустить

1. Один раз скачать [Windows x64 лаунчер](https://github.com/Timofei2506/lestingcraft-new-era/actions/runs/38736871408/artifacts/11974517325) из своего GitHub-аккаунта с доступом к репозиторию.
2. Распаковать **весь** архив, оставив `test-access.key` рядом с `LestingCraftLauncher.exe`. Не запускать EXE внутри ZIP. Ключ — приглашение в тестовый канал, не GitHub/Cloudflare-токен; не публиковать его.
3. Запустить `LestingCraftLauncher.exe`, нажать **«Обновить»**, после установки — **«Играть»**. Если игра уже распакована, кнопка **«Уже есть игра?»** позволяет использовать совпадающие файлы из старой папки.
4. Для следующих игровых обновлений достаточно лаунчера. Unity Editor/Hub, .NET/SDK и права администратора на ПК пользователя не нужны.

Установленная игра запускается офлайн. Отмена/ошибка обновления оставляет прежнюю выбранную установку. Есть откат. Сохранения находятся отдельно в Unity LocalLow, лаунчер их не удаляет. EXE пока без издательской цифровой подписи: возможен SmartScreen; не нужно отключать антивирус. Сам лаунчер пока обновляется вручную. Артефакты временные: манифесты канала и пакет лаунчера хранятся 14 дней; это не постоянный релизный хостинг.

## Игровые изменения

- Убраны верхние плашки мира/seed/режима/FPS/чанков, постоянная строка задания и подсказки клавиш. Управление доступно в паузе. Иконки хотбара и силуэт состояния сохранены.
- Добавлен чат комнаты по **Enter/T**; Escape закрывает ввод. Во время набора движение и добыча блокируются. Сообщения исчезают через 9 секунд и не записываются в сохранение. Сервер ограничивает длину до 240 символов и частоту; имя берётся из авторизованного соединения.
- Добыча использует DDA по актуальным вокселям вместо Physics.Raycast по посторонним/устаревшим коллайдерам. Изменённые чанки получают приоритет перестройки. Добавлены рамка цели, нарастающие трещины и процент добычи. Creative: 0,24 секунды на блок вместо 0,01.
- Можно ставить блоки в воду. Касание пола ногами не считается пересечением тела; установка внутрь игрока запрещена. Требования кирки в выживании сохранены, отказ объясняется уведомлением.
- Облака: seeded noise вместо регулярной синусной текстуры, domain warp, разные масштабы и непрерывная ветровая адвекция. Смягчён свет облаков/солнца.
- Дождь: укороченные полосы без случайного поворота, объёмное распределение высоты, мягкий шейдер и затухание у камеры/геометрии.
- Вода: менее резкие нормали, повёрнутая вторая волна и менее регулярная береговая пена. Высокое качество не заменялось скрытым auto-low.

## Ошибка, остановленная до выдачи обновления

Ручной аудит обнаружил, что ранний `BlockFeedback` двигал transform владельца Player. Непроверенный Windows-run `38738329950` отменён до публикации и никогда не попадал в канал. Исправление `ef92bc91` создаёт отдельный визуальный корень в World; outline использует собственный шейдер из Resources, а не потенциально вырезаемый URP/Unlit. Финальный commit `1d718db3` заставляет новый регрессионный тест действительно выполнять LateUpdate на inactive EditMode fixture через reflection. Проверены неизменность позиции игрока, положение и независимый поворот рамки, отсутствие коллайдеров; этот тест вошёл в успешные 123/123.

## Доступ и ограничения

Используется существующий бесплатный Cloudflare Worker и закрытые GitHub Actions artifacts, без R2/Neon/платных сервисов. Инфраструктурный PAT находится только на серверной стороне и в encrypted Secrets, не в лаунчере/игре/исходниках. До отзыва временного широкого PAT нужно заменить `LAUNCHER_READER` в GitHub и Worker на repo-only Actions read-only credential; иначе новые скачивания прекратятся, но установленная игра останется доступной офлайн. Переданные ранее инфраструктурные секреты следует ротировать.

Защита от downgrade развёрнута: если пакет последней успешной native-сборки истёк, канал возвращает недоступность, а не молча откатывает игрока на bootstrap. Бинарных патчей, побайтового продолжения прерванного файла, автоматической очистки старых версий и автоматического обновления самого лаунчера пока нет.
