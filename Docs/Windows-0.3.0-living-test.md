## Запуск

Распаковать **весь** архив в отдельную папку и запустить `LestingCraft.exe`. Не вынимать EXE отдельно из папки, не запускать прямо из ZIP. Unity/Hub/SDK не нужны. Сборка для Windows x64, не Android. Обычный запуск использует видеокарту; WARP включался только для автоматической облачной проверки.

## Включено

Вся текущая Unity-часть: материалы/вода/лава/прозрачные кристалл и стекло; физика падающих блоков и предметов, персонажа/животных; шесть зон HP с травмами; жители/торговля/кот; алмазы, оружие/лук/кирки, структуры, обязательное начало и добровольное продолжение главы, аккаунты и 200 достижений. Это не означает, что остальные четыре сюжетные главы закончены. Схема мира rules9/content6 сохраняет старые ландшафты.

## Настоящие проверки

Графическое устройство — Direct3D11 / Microsoft Basic Render Driver (WARP). PASS: меню, 98 иконок, мир, настоящее вступление, 63 слоя всех трёх PBR-массивов, шесть зон тела, нативные модели жителей/кота и deer/hare/boar, руки и силуэт, восемь слотов одежды/брони, hover, 2×2/3×3, реальная готовка печи с расходом топлива, дым/искры и форма/коллизия/выбор кристалла.

SSAO: 656802 пикселя с выборкой, 127844 с окклюзией. SSR воды: 51776 настоящих попаданий чтения depth/ray. Это **не hardware RTX**. Нативные кадры Medium/Ultra получены; девять PNG из EXE находятся отдельными файлами в `.arena/Windows-0.3.0-actual-screenshots/`, а также в SmokeResults архива. Прежние десять изображений не выдаются за текущие.

WARP — программная графика: это проверка корректности, **не FPS-бенчмарк пользовательского GPU**. Полная кампания/долгая кооперативная сессия/все травмы и AI в нативной игре не пройдены целиком.

Публичный игровой Worker обновлён до rules9. Настоящие два WebSocket-клиента прошли лобби/start, торговлю, приручение/сидение/владение, физический дроп изношенного оружия, переподключение. Регистрация/вход/восстановление и удаление синтетического профиля проверены на живом Cloudflare после исправления KDF; 113 Node-тестов PASS. Подробности: `Validation/windows-living/cloud-server.txt`.

Исправлено по реальным Windows-логам: UTF-8 preflight; вырезанный Unity шейдер вступительной крови (теперь сериализованный Resources-материал); аварийный smoke теперь завершает процесс сразу, а не спамит исключениями. Ошибки не скрывались отключением сцены или понижением качества.
