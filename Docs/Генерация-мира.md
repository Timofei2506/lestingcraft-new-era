# Генерация мира: версия 2 (Лестингия)

Версия генератора: `TerrainGenerator.Version = 2`. Она входит в протокол: клиент и сервер должны совпадать, мир версии 1 не загружается. Старые сиды и сохранения версии 1 не переносятся.

## Что изменилось в Лестингии

- **Океан и побережье.** Низкочастотный шум материков (`continent`) задаёт океан, сушу и пляжи. Вода заполняет всё ниже уровня моря `SeaLevel = 40`.
- **Биомы.** Равнины, лес, пустыня, снег (ели), болото, горы и океан. Биом выбирается по температуре, влажности и высоте.
- **Горы.** Ridged-шум поднимает хребты до ~80 блоков. Вершины выше 72 покрыты снегом, склоны — камнем.
- **Реки.** Тонкие извилистые контуры шума врезаются до уровня 35, и река заполняется водой до уровня моря.
- **Деревья.** Сетка 7×7, шанс зависит от биома: лес 70%, болото 30%, снег 35%, равнины 8%. Дуб и ель разной формы.
- **Руда глубже.** Вероятность руды: 1/60 при y<20, 1/110 при y<40, 1/170 выше.

Новых ID блоков нет: все биомы используют существующие блоки (песок, дёрн, земля, камень, снег, дерево, листва, руда, вода). Поэтому ассеты и материалы не менялись.

Другие измерения (Ашленды, Небокрай, Склеп Эха, Разлом Хаоса) по-прежнему работают по формулам версии 1.

## Проверка

- Unity EditMode: `WorldGenerationTests.cs` и `WorldGenerationV2Tests` (запускаются в CI).
- Локальный харнесс без Unity: `Tools/worldgen-harness`. Он компилирует реальный `TerrainGenerator.cs` с заглушками Unity-API.
  - `cd Tools/worldgen-harness && dotnet run -c Release` — проверки детерминизма, джобы, блоков, биомов, воды, руды, деревьев и скорости.
  - `dotnet run -c Release -- map out.ppm 512` — карта сверху для визуальной проверки.

Скорость (обычный C#, один поток, без Burst): около 1.5–2.5 мс на чанк. Burst в Unity работает быстрее.

## Ограничения

- Материки пока небольшие и разбитые. Это видно на карте; для более крупных континентов нужна отдельная настройка масштаба, что тянет за собой перенастройку порогов биомов.
- Визуально проверено только по карте сверху. Вид в игре (освещение, тени, текстуры) ещё не смотрели.
- Деревья на краях чанков детерминированы (считаются из любой точки), но их объём в игре ещё не измерялся.
