# Планетарные боссы: воксельные скульпты v3 (в игре)

## Что заменено
Прежний внутриигровой риг боссов собирался из растянутых `GameObject.CreatePrimitive(Cube)`
с плоскими URP-Lit цветами: одинаковый гуманоид на все миры, светящийся куб-«реактор» на груди,
кубическое кольцо-телеграф. Это нарушало утверждённый арт-стандарт
(`Docs/Планетарные-боссы-art-direction.md`) и выглядело как заглушка.

Теперь каждый страж — **одна авторская воксельная скульптура** в том же стиле, что и
одобренный Страж корней v2: surface-culled меш без внутренних граней, непрерывные
PBR-текстуры по слою материала, эмиссия только в трещинах/сердце/глазах, отдельные
шарнирные части (руки, ноги, голова, челюсти, плавники, орбитальные осколки).

## Конвейер
1. `Assets/Scripts/Gameplay/BossSculpt.cs` — чистое C#-ядро без Unity-типов: кисти
   (эллипсоид со скошенным сечением, короб, оболочка, Catmull-Rom конечности, кольца,
   трещины-прожилки, глаза с радужкой и зрачком) и 16 авторских стражей + 2 дополнительных
   босса Земли + 7 дронов + моб Сущность 23. Детерминировано по seed.
2. `Assets/Scripts/Presentation/BossSculpture.cs` — построитель мешей: одна сетка на часть,
   отсечение_shared граней, UV в метровом пространстве со слоем материала, tint/emission через
   vertex color, общий материал `Generated/VoxelObjects` (настоящий PBR-массив текстур).
3. `PlanetaryBossController` (Assets/Scripts/Runtime/SpaceFlightVisuals.cs) — боевые правила не
   изменены; анимации используют шарниры: шаг рук, сгибание в телеграф, парение левитирующих
   архонтов, вращение осколков, пульс сердца и вспышка попадания через эмиссию вершин.
4. Дроны и Сущность 23 получили такие же маленькие скульпты вместо кубов.

## Честная проверка без Unity
- `Tools/check_boss_sculpt_core.cs` (mono, 328 утверждений): размеры, наземная линия,
  шарнирность, палитры с эмиссией и матовыми слоями, уникальность силуэтов между мирами,
  детерминированность. Запускается в CI (`core.yml`).
- `Tools/check_boss_sculpt_layers.py`: каждый слой палитры существует в `SurfaceLayers.Names`
  и имеет реальные albedo/normal/mask в `Assets/Art/PBR`.
- `Tools/export_boss_sculpts.cs` + `Tools/preview_boss_sculpts.py`: офлайн-превью тех же самых
  данных (софт-рендер с настоящими albedo-текстурами, студийный свет, без утверждений о URP).
  Результаты лежат в `ArtSource/BossModels/SculptPreviews/` (контактный лист + отдельные виды).
  Это НЕ скриншоты Unity: рендер в URP, тени, bloom и производительность ещё предстоит проверить
  реальной сборкой.
