# Отдельные сгенерированные текстуры животных

16 октября 2026. Дополнение к итерации 11, **в исходниках, не новая Windows-сборка**.

## Три новых AI-изображения

Оригиналы сохранены без замены общей текстуры перекраской:

| Вид | Исходное изображение | Назначение |
|---|---|---|
| Олень | `ArtSource/Textures/Animals/deer-fur.jpg` | Короткий гладкий рыже-коричневый мех |
| Заяц | `ArtSource/Textures/Animals/hare-fur.jpg` | Мягкий серо-бурый мех с тёмными кончиками волосков |
| Кабан | `ArtSource/Textures/Animals/boar-bristles.jpg` | Грубая тёмная щетина со светлыми кончиками |

Из этих оригиналов созданы три отдельных PBR-комплекта 512×512, а также два вспомогательных: светлый подшёрсток для живота/хвоста/внутренней части ушей и тёмная поверхность носа/копыт. Вспомогательные поверхности получены обработкой исходных изображений, а не отдельными вызовами AI.

Каждый комплект содержит albedo JPEG q95 4:4:4, RGB normal PNG и RGBA metallic/AO/height/smoothness PNG. Это **оценочные карты из изображения, не измеренные сканы**. Металличность — нулевая; грубость и сила нормали различаются для гладкого меха, мягкого подшёрстка, щетины и более гладких твёрдых участков.

## Подключение

- Общая текстура `wildlife-fur` больше не назначается телам трёх животных. Она сохранена для прежних предметов, например шкуры.
- `AnimalVisual.FurLayerForSpecies` выбирает отдельные слои 52/53/54 для оленя/зайца/кабана. Основной цвет тела берётся из изображения; прежняя перекраска одного меха отключена.
- Подшёрсток — слой 55, твёрдые тёмные участки — слой 56. У зайца лапы используют мех, а не копыта.
- Глаза, рога и клыки остаются прежними авторскими блочными деталями. Отдельные AI-изображения этих деталей не генерировались.
- Всего в массиве теперь **57 PBR-слоёв**. Старые индексы не переставлены. Схема сохранения и сетевые ID не менялись.

Сборщик: `Tools/build_animal_materials.py`. Для полного воспроизведения после прежних материалов:

```text
python Tools/build_materials_v6.py
python Tools/build_animal_materials.py
python Tools/build_voxel_items.py
python Tools/check_art.py
python Tools/check_content.py
```

Редактор Unity пересоздаёт текстурные массивы по числу слоёв и хешу изображений. Без запуска редактора уже собранный старый EXE сам эти файлы не подхватит.

Это не графическая проверка в Unity/EXE. Новая сборка, публикация и GPU-прогон не выполнялись. Оригиналы показанных изображений являются текстурами, а не игровыми скриншотами.
