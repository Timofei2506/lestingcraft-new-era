# Сборка в облаке — без установки Unity на ПК

Главная идея: **редактор Unity не нужен**. Проект лежит в git, Unity поднимается в докере на
GitHub Actions, лицензия оформляется через браузер. Ты скачиваешь готовый билд или играешь в WebGL по ссылке.

Единственное, что понадобится: **бесплатный аккаунт Unity ID** (регистрация в браузере, без установки чего-либо).

---

## Шаг 1. Секрет `UNITY_LICENSE` (один раз, ~5 минут)

1. Открой **Actions** → workflow **«Generate Unity activation file (ALF)»** → **Run workflow**.
2. Когда job завершится, скачай артефакт **`unity-alf`** — внутри файл `Unity_v6000.0.32f1.alf`.
3. В браузере открой **https://license.unity3d.com/manual** → войди в Unity ID (бесплатный аккаунт).
4. Загрузи скачанный `.alf` → нажми **Next** → скачай файл **`.ulf`** (лицензия).
5. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `UNITY_LICENSE`
   - Value: **всё содержимое** файла `.ulf` целиком (это XML).
6. (Опционально) Создай переменную репозитория `UNITY_VERSION` = `6000.0.32f1`, если захочешь менять версию в одном месте.

> ⚠️ Файлы `.alf`/`.ulf` — это лицензионные ключи. Никогда не коммить их в репозиторий
> (`.gitignore` уже их игнорирует) и не публикуй.

## Шаг 2. Тесты (CI)

Workflow **CI** запускается автоматически на каждый push в `main`/`develop` и на pull request'ы:
EditMode-тесты ядра мира (чанки, реестр блоков) через `game-ci/unity-test-runner`.
Пока секрет не настроен — CI будет падать с ошибкой лицензии, это ожидаемо.

## Шаг 3. Билд

Два способа:
- **Actions → Build → Run workflow** — соберёт Windows и WebGL прямо сейчас;
- **Запушить тег** (`git tag v0.1.0 && git push --tags`) — соберёт и автоматически:

| Куда | Что попадёт |
|---|---|
| **Releases** | `build-StandaloneWindows64.zip` (Windows-игра) и `build-WebGL.zip` |
| **GitHub Pages** | WebGL-версия как играбельный сайт (ссылка — во вкладке Pages / в логе job'а) |

> Для Pages один раз включи: **Settings → Pages → Source: GitHub Actions**.

## Шаг 4. Играем

- **Windows:** скачай zip из Releases → распакуй → `LestingCraft.exe`.
- **WebGL (слабый ПК):** открой ссылку Pages в браузере — установок ноль.

## FAQ

**Мой ПК слабый — потянет?**
Сборка вообще не использует твой ПК. Для игры: WebGL-версия в браузере — самый лёгкий путь;
Windows-билд будет с настройками графики (прорисовка, дальность).

**А если захочу открыть проект в редакторе?**
Не обязательно. Если когда-нибудь захочется — Unity Hub + Unity 6 LTS, открывается как обычный проект.

**Лицензия закончится?**
Персональная лицензия действует ~1 год, обновляется тем же способом через браузер.

**CI ругается на пакеты (`manifest.json`)?**
Подними патч-версии пакетов в `Packages/manifest.json` до свежих для 6000.0.x — обычно помогает.
