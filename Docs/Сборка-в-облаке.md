# Облачная сборка Windows — без Unity на ПК игрока

Текущая платформа: **Windows x64**. Браузерная версия и публикация на GitHub Pages отложены. Бесплатный Cloudflare backend работает с Windows-клиентом и от WebGL не зависит.

## Настройка облака

Unity Editor устанавливается только на runner. Версия задана в `ProjectSettings/ProjectVersion.txt`. Для Personal-активации используются зашифрованные Actions secrets:

| Секрет | Назначение |
|---|---|
| `UNITY_USERNAME` | Unity ID email |
| `UNITY_PASSWORD` | Пароль Unity ID |

Не записывать пароли, PAT и ключи Cloudflare в проект, Resources или сообщения. На ПК игрока Unity Hub/Editor не нужны.

## Проверка исходников

Workflow **CI** запускает EditMode-тесты. Он не создаёт скачиваемую игру и не публикует релиз. Ubuntu runner освобождает место перед установкой Unity; это не затрагивает ПК автора/игрока.

## Тестовая игра

1. Только после согласования новой сборки: **Actions → Build Windows → Run workflow**.
2. Собирается единственная цель `StandaloneWindows64` методом `BuildScript.BuildWindows64`.
3. После success скачать артефакт `build-StandaloneWindows64`.
4. Распаковать ZIP **полностью**, сохранив `.exe`, папку Data и DLL рядом.
5. Запустить `LestingCraft.exe`. Это портативная игра, не установщик Unity.

Workflow dispatch не публикует GitHub Release. Теги `v*` предназначены для будущего согласованного релиза; не создавать ранний тег ради теста. Старая версия/история прогонов не являются новой графической сборкой.

## Проверки графики

Прежняя Windows-сборка запускалась у автора и была играбельной. Основным замечанием было визуальное качество. Новые PBR-материалы, эффекты, GUI и M2 требуют нового Windows runtime-теста; успешные тесты исходников его не заменяют. Прежний сбой WebGL — отдельная платформенная проблема, не доказательство сбоя Windows.

## Технические детали

- `buildalon/unity-setup@v2` + Hub 3.12.0 устанавливают Editor на runner.
- `buildalon/activate-unity-license@v2` активирует Personal через Unity ID и возвращает seat.
- `buildalon/unity-action@v3` запускает тесты/сборку в batch mode.
- CI/Build делят concurrency-группу `unity-license`, чтобы не занимать несколько мест лицензии одновременно.
- `PresentationAssets.Ensure()` воспроизводит texture arrays, материалы, URP pipeline и volumes из исходников.
- BuildScript требует `Succeeded` **и** `totalErrors == 0`, поскольку Unity может вернуть Succeeded с ошибкой отдельного shader pass.
- Сайт показывает только готовые стабильные релизы с настоящим Windows ZIP. Наличие WebGL ZIP больше не требуется.
