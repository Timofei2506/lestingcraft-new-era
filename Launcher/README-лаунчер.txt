LESTINGCRAFT · NEW ERA — ЛАУНЧЕР WINDOWS x64, тестовая версия

1. Распакуйте весь архив в любую удобную папку. Запустите LestingCraftLauncher.exe.
   .NET, Unity Editor и права администратора не нужны.
2. Если в частном архиве есть test-access.key, тестовый доступ подхватится автоматически.
   Это только приглашение на скачивание игровых сборок, НЕ GitHub/Cloudflare-токен.
   Не выкладывайте этот ключ публично. Его можно заменить на сервере.
3. Нажмите «Обновить», затем «Играть». При следующих обновлениях скачиваются только
   изменившиеся файлы + небольшая ZIP-таблица. Каждый файл проверяется SHA-256.
4. «Уже есть игра?» позволяет выбрать распакованную папку с LestingCraft.exe:
   совпадающие по SHA-256 файлы будут использованы без повторной загрузки.
5. Сохранения Unity находятся отдельно в LocalLow/LestingCraft/LestingCraft New Era;
   лаунчер их не удаляет. Незавершённое/повреждённое обновление не переключает версию.
6. Установленная версия запускается без интернета. «Откат версии» возвращает предыдущую.

Пока это тест: EXE не имеет платной цифровой подписи, возможен SmartScreen.
Проверяйте источник и SHA256.txt; не отключайте антивирус ради запуска.
Сам лаунчер пока обновляется вручную отдельным архивом, игра — через интерфейс.
GitHub Actions хранит игровые пакеты ограниченное время (новые — минимум 14 дней).
Если пакет истёк, установленная игра остаётся доступна офлайн, нужен новый cloud build.

Исходники приватные. Полного релиза/тега игры эта сборка не создаёт.
Лаунчер не включает рекламные SDK, телеметрию и GitHub/Cloudflare credentials.
