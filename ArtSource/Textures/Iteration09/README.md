# Iteration 09 texture source

Three original AI-generated albedo images: stone, meadow turf and oak bark. JPEG masters at 1024² preserve source within the project snapshot budget. `Tools/refine_materials_v4.py` creates seven 512² periodic albedo/normal/packed-mask material sets. Normal, height and roughness maps are derived estimates, not photogrammetry or scanned physical data. All 24 runtime material layers remain mapped. Runtime relief is parallax occlusion, not mesh displacement.
