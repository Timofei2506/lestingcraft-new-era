# LestingCraft: New Era

[![CI](https://github.com/Timofei2506/lestingcraft-new-era/actions/workflows/ci.yml/badge.svg)](https://github.com/Timofei2506/lestingcraft-new-era/actions/workflows/ci.yml)

> Воксельная песочница с **5 измерениями**, боссами и прогрессией от кулака до Повелителя Хаоса.
> Движок: **Unity 6 LTS (URP)**. Сборка: **полностью в облаке** — GitHub Actions, без установки Unity на свой ПК.

## О игре

**LestingCraft: New Era** — не «ещё один клон», а игра на четырёх столпах:

| Столп | Смысл |
|---|---|
| 🌍 **Мир** | Живые биомы, пещеры, структуры, 5 измерений с порталами |
| ⛏️ **Вертикалька** | Добыча → крафт → экипировка → портал → босс |
| 👹 **Боссы** | Фазовые бои с уникальными аренами, а не «большой моб с ОЗ» |
| ⚡ **Производительность** | 60 FPS на средних ПК, Burst/Jobs-генерация мира |

## Как играть — ничего не устанавливая

Твой ПК **не нужен для сборки**: Unity живёт в облаке (GitHub Actions), готовые сборки падают в **Releases**,
а WebGL-версия выкладывается на **GitHub Pages** как сайт.

1. Добавить в репозиторий два секрета (в браузере, 2 минуты): `UNITY_USERNAME` и `UNITY_PASSWORD` — email/пароль от бесплатного Unity ID. Подробно: **[Docs/Сборка-в-облаке.md](Docs/Сборка-в-облаке.md)**.
2. Запустить workflow **Build** (или запушить тег `v0.1.0`).
3. Забрать `build-StandaloneWindows64.zip` из Releases **или** открыть ссылку Pages (WebGL).

> Как это работает без Unity: редактор ставится прямо на раннер GitHub, лицензия берётся
> онлайн-входом по Unity ID (Personal), сборка и тесты крутятся в Actions. На твоём ПК — ничего.

## WORLD LAB / Co-op — первый игровой срез

- Seed-генерация пяти ландшафтов: поверхность с деревьями/пещерами/рудой, огненный, парящие острова, кристаллический и хаотический. Это ещё не полноценные измерения с порталами/боссами.
- Колонки 16×256×16, Burst/Jobs-генерация, стриминг по дистанции, меши только видимых граней и отдельные коллизии твёрдых блоков. Мешинг пока CPU/main-thread, **не greedy**.
- Первый персонаж: WASD/мышь/Space/Shift, установка/удаление блоков, выбор материалов 1–9, меню Esc.
- Комнаты для 2–8 игроков: общий seed, отображение игроков, подтверждённые сервером изменения блоков, сохранение дельты и snapshot при входе.
- В кооперативе мир 128×128×256, до 4096 изменённых ячеек. Офлайн координаты ограничены ±32000; офлайн-правки пока без дискового сохранения.

**Сервер:** https://lestingcraft-coop.kroterallitir.workers.dev (`/health` — API, не игра). URL уже задан в клиенте. Для игры нужен WebGL/Windows-билд из Actions; отсутствие Unity на компьютере не мешает.

**Документация для будущих владельцев серверов:** [кооператив, Cloudflare, Node, Docker и протокол](Docs/Мультиплеер-и-хостинг.md). Standalone backend не требует Cloudflare/R2/Neon.

Это технический срез, а не завершённый M1 или релиз игры: 60 FPS и визуальный двухклиентный тест ещё не подтверждены; без инвентаря, крафта, мобов, авторитетной физики и античита.
