# LestingCraft: New Era — Кооперативный сервер и API

Серверная часть кооператива до 8 игроков, синхронизации состояний мира, фауны, боссов, межпланетных перелётов и игровых аккаунтов. Поддерживает два режима развёртывания:
- **Cloudflare Workers + SQLite Durable Objects** (`wrangler.toml`, классы `GameRoom`, `RoomDirectory`, `AccountDirectory` с поддержкой WebSocket Hibernation API).
- **Standalone Node.js 22 LTS** (`standalone.js` / `Dockerfile` для локального или выделенного хостинга без облачных зависимостей).

## Протокол комнат и лобби

Создание комнаты включает версию протокола, `rulesVersion`, игровой режим (`0..3`), стартовое измерение, `seed` и приватный `ownerKey` хоста (сервер автоматически вырезает приватные ключи из публичных ответов и списков миров).

Новые мультиплеерные сессии стартуют через лобби с идентификацией `hostId`: старт игры подтверждается пакетом `lobby_start`, после чего синхронизируются дельты блоков, мировые часы, фазы сюжетных сцен, состояния механизмов и боссов, а личный инвентарь и награды сохраняются за каждым участником. Обратная совместимость со старыми версиями контента комнат сохранена без принудительной перегенерации ландшафта.

## Тестирование

```bash
cd Server
npm ci
npm test
```

Набор тестов проверяет контракты лобби, ревизий чанков, сюжетной синхронизации, сохранения состояния при переподключении, орбитальных пакетов и защиты данных аккаунтов (автоматически запускается в `.github/workflows/server.yml`).
