01 / САМОСТОЯТЕЛЬНЫЙ BACKEND

Node.js 20+ / 22 LTS

Клонируйте проект на VPS или другой машине для хостинга. Укажите постоянную директорию данных. Это серверный код, не Unity Editor.

TERMINAL
git clone https://github.com/Timofei2506/lestingcraft-new-era.git
cd lestingcraft-new-era/Server
npm ci --omit=dev
PORT=8787 DATA_DIR=/srv/lestingcraft-data npm start
Команды для Windows PowerShell
TERMINAL
$env:PORT = "8787"
$env:DATA_DIR = "C:\lestingcraft-data"
npm start
02 / В КОНТЕЙНЕРЕ

Docker и постоянный том

Dockerfile есть в репозитории. Обязательно подключите том для сохранений: замена контейнера не должна удалять ваш мир.

TERMINAL
cd Server
docker build -t lestingcraft-server .
docker volume create lestingcraft-worlds
docker run -d --name lestingcraft --restart unless-stopped \
  -p 8787:8787 -v lestingcraft-worlds:/data lestingcraft-server

Node backend и протокол проверены. Запуск Docker-контейнера в среде разработки пока отдельно не проверялся.

03 / БЕЗОПАСНОЕ СОЕДИНЕНИЕ

HTTPS для браузера

WebGL на HTTPS-странице требует HTTPS/WSS сервер. Вариант с Caddy: направьте DNS своего домена на VPS и откройте порты 80/443.

TERMINAL
play.example.com {
    reverse_proxy 127.0.0.1:8787
}

В игровом меню укажите https://play.example.com. Caddy проксирует WebSocket. Не выставляйте незашифрованный сервер для публичной игры.

04 / ЧТОБЫ МИР НЕ ИСЧЕЗ

Сохранения и резервная копия

Standalone хранит параметры комнат и изменения в JSON-файлах DATA_DIR. Остановите сервер и скопируйте всю директорию. При восстановлении верните файлы и подключитесь по прежнему коду комнаты.

Код комнаты — ключ доступа. Не включайте сохранения в публичный репозиторий. Автоматический экспорт Cloudflare-комнат пока не реализован.
05 / ПЕРЕД ПУБЛИЧНЫМ ХОСТИНГОМ

Прототип, не production

До восьми игроков и 4096 изменённых ячеек на комнату. Запись standalone JSON синхронная; большой нагрузке нужны другое хранилище и дополнительная защита. Нет авторитетной физики, ролей и античита.

Node лимитирует создание комнат по непосредственному IP. За reverse proxy один адрес может оказаться общим для всех. Не доверяйте произвольному X-Forwarded-For без настройки доверенных прокси.
