Вопросы

Частые вопросы

Это готовая игра?

Нет. Это ранний прототип. Крафт, мир, сюжетные сцены и кооператив работают, но многое ещё в планах.

Где скачать игру?

Откройте раздел «Скачать» и выберите Windows или Android. Кнопка ведёт напрямую к последней опубликованной проверенной сборке. Если релиза ещё нет, страница честно покажет, что он пока не опубликован.

Нужна ли Unity или .NET для запуска?

Нет. Windows-версия запускается из распакованного ZIP без Unity Editor. Для Android установите APK. Для сетевой игры потребуется доступ к интернету; одиночный режим не требует лаунчера.

Что делает лаунчер?

Скачивает только изменившиеся файлы и проверяет каждый по SHA-256. Прежняя версия остаётся до успешной установки новой. Есть откат. Сохранения лежат отдельно и лаунчером не удаляются.

Собирает ли лаунчер телеметрию?

Нет. В лаунчере нет рекламных SDK, аналитики и телеметрии. Код приглашения хранится только на вашем компьютере, в зашифрованном виде Windows (DPAPI).

Будет ли игра платной?

Модель распространения пока не выбрана. Решим до публичного релиза и сообщим здесь заранее.

Где исходный код?

Исходники доступны для просмотра в репозитории на GitHub; повторное использование ограничено. См. условия лицензии.
