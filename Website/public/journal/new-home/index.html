Место для всей вселенной

На сайте собраны измерения, статус разработки, журнал и документация. Концепт-арт помогает передать настроение, но не выдаётся за геймплей.

Загрузка — только когда есть что загружать

Удалён ранний предрелиз без готовых игровых архивов. Раздел загрузок проверяет GitHub Releases и проверенный индекс и показывает только опубликованные стабильные версии с готовым Windows-архивом. Неполный или черновой релиз не превращается в кнопку «Скачать».

Сервер принадлежит вам

Backend отделён от Unity-клиента. Для будущих владельцев серверов предоставлены Node.js, Dockerfile и инструкция HTTPS-проксирования. Обязательной привязки к нашему Cloudflare нет.
