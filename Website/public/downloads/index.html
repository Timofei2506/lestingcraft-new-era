ДО ПЕРВОГО ЗАПУСКА

Выбери свой путь.

01

Windows

Когда сборка появится: скачать ZIP, распаковать папку целиком и запустить LestingCraft.exe. Unity Editor не потребуется.

02

Кооператив

Запустить Windows-клиент, создать комнату и передать код друзьям. Браузерная версия отложена; сервер работает отдельно от клиента.

03

Свой сервер

Backend уже есть в исходниках. Для хостинга нужны Node.js или Docker и HTTPS для браузерных клиентов. Это отдельный сервер, не установка Unity.
