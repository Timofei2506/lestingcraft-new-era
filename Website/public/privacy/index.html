Техническая информация о работе этого сайта. Версия описания: 14 октября 2026.

Что делает сайт

Сайт показывает информацию об игре, проверяет готовые GitHub Releases и доступность сервера кооператива через собственные API-маршруты. Нет регистрации, форм рассылки, платежей, рекламных пикселей или клиентской аналитики.

Шрифты и изображения

Файлы шрифтов и иллюстраций размещены вместе с сайтом. Браузер не обращается к Google Fonts за шрифтами. Концепт-арт создан с помощью ИИ и помечен отдельно от геймплея.

Техническая обработка

Хостинг Cloudflare может обрабатывать IP, заголовки запросов и технические сведения для доставки сайта и защиты инфраструктуры. Запросы к GitHub API выполняются серверной частью сайта; при переходе на GitHub или скачивании архива действуют правила GitHub.

Cookies и локальное хранение

Собственных cookies и постоянного профиля посетителя сайт не создаёт. Копирование адресов и команд обращается к буферу обмена только после нажатия кнопки.

Игровой сервер — отдельно

В кооперативе передаются выбранное имя, позиция и правки блоков. Сервер сохраняет параметры комнаты и изменения мира. Коды комнат дают доступ к миру; делитесь ими только с теми, кому доверяете.

Обратная связь

Технические вопросы можно оставить в GitHub Issues. Не публикуйте пароли, личные данные или API-токены.
